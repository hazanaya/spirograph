# Instructions for Contributors (Human and AI)

## Before Starting Work
1. Read `docs/HANDOFF.md` for current state
2. Read `docs/DECISIONS.md` for past choices
3. Check `docs/CHANGELOG.md` for recent changes

## While Working
- Commit frequently with clear messages
- Log new dependencies or architectural decisions in `docs/DECISIONS.md`
- Follow existing code patterns

## Before Ending a Session
1. Update `docs/HANDOFF.md` with current state
2. Update `docs/CHANGELOG.md` with changes made
3. Log any decisions in `docs/DECISIONS.md`
4. Commit all changes
